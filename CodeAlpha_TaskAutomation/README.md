# 📁 CodeAlpha Task Automation

A Python automation project developed as part of the CodeAlpha Python Programming Internship.

## 📌 Project Overview

This project automatically moves all `.jpg` files from one folder to another.

## ✨ Features

- Takes source folder from the user
- Takes destination folder from the user
- Finds JPG files automatically
- Creates the destination folder if needed
- Moves JPG files
- Displays the number of files moved

## 🛠️ Technologies Used

- Python 3
- os
- shutil
- File handling

## ▶️ How to Run

```bash
python main.py
